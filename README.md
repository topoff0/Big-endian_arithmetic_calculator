# Big-endian_arithmetic_calculator

## Coursework (2nd year, "Discrete Mathematics")
To generate a calculator of "large" finite arithmetic (8 digits) for four operations (+, –, *, ÷) based on "small" finite arithmetic, where the rule "+1" is given and the properties of commutativity (+,*), associativity (+, *), distributivity * relative to + are met, additive unit "a" and multiplicative unit "b" are set, and the property: for (every x) x*a=a. Additionally, you can implement exponentiation, GCF and LCM search for two numbers (in my case only exponentiation was implemented ^_^).
